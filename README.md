### Project Structure

### Routes:
- ```"/"``` : home page, where users can view all blog posts
- ```"/posts/:id/``` : view post
- ```"/create"``` : create post
- ```"/update"``` : update post
- ```"/delete"``` : delete post

### Tech Stack
- Front-end: HTML, CSS, JS
- Back-end: Node, Express, EJ

### Install
run ```npm install`` to install dependencies
